# STM32F407 编码器触发 ADC 采集与 USB CDC 上传固件

基于 STM32F407 的裸机固件：以**编码器信号**作为硬件触发源驱动 ADC 采样，采样数据经**环形队列**缓冲后由 **USB CDC 虚拟串口**上传至上位机；同时利用每转一次的 **Z 相脉冲**测量转速，并按固定周期上报转速帧。

工程采用 `APP → SERVICE → PLATFORM ← IMPLEMENT → VENDOR` 的分层多态架构，业务逻辑与 STM32 硬件完全解耦。

---

## 功能特性

- **编码器触发采样**：PA5（TIM2_CH1）编码器上升沿触发 ADC1 转换，采样率与转速天然同步
- **DMA 环形搬运**：ADC1 → DMA2 双缓冲（1024 半字），半满/满中断批量提交，CPU 开销极低
- **两级异步缓冲**：驱动层 DMA 环形缓冲 + 服务层 16 KB 字节环形队列，解耦采样速率与 USB 发送速率
- **背压保护**：队列水位过高或 USB 端点忙时自动 `pause` 采样，恢复后 `resume`，并统计丢样与忙次数
- **Z 相测速**：PB12 每转一个脉冲，TIM5（1 MHz）记录周期，换算转速，超时自动归零
- **上位机命令控制**：`O\0` 启动采集、`C\0` 停止采集（停止时冲刷 DMA 与队列残余数据）
- **串口调试遥测**：USART1 每秒输出一行 `D ...` 运行指标（转速、DMA 中断、队列水位、错误计数等）

| 项目 | 说明 |
|---|---|
| MCU | STM32F407VETx（Cortex-M4F，512 KB Flash / 128+64 KB RAM） |
| 开发板 | ALIENTEK Explorer（正点原子探索者） |
| 外部晶振 | 12 MHz |
| 调试器 | J-Link |

### 引脚分配

| 引脚 | 功能 | 说明 |
|---|---|---|
| PA2 | ADC1_IN2 | 模拟量输入，采样时间 56 周期 |
| PA4 | 相位 A | GPIO 输入（编码器 A 相） |
| PA5 | 相位 B / 触发 | TIM2_CH1 单边沿输入，**每个上升沿触发一次 ADC** |
| PB12 | Z 相 | 每转一个脉冲，用于周期测速 |
| PA11 / PA12 | USB OTG_FS | 全速 USB，CDC 虚拟串口 |
| PA9 / PA10 | USART1 | 调试串口，115200-8-N-1 |

### 定时器用途

- **TIM2**：编码器脉冲输入与 ADC 外部触发源
- **TIM5**：72 MHz / 72 = **1 MHz** 自由运行计数器，为 Z 相边沿打时间戳

## 软件架构

```
        ┌──────────────────────────────────────────┐
        │  USER/main.c           → app_main()      │  启动入口
        ├──────────────────────────────────────────┤
        │  APP/app_main.c        → 主循环编排      │  应用层
        ├──────────────────────────────────────────┤
        │  SERVICE/adc_stream_service.c            │  服务层（业务状态机）
        │    · 收发环形队列  · 命令解析  · 转速帧  │
        ├──────────────────────────────────────────┤
        │  PLATFORM/platform_*.h                   │  平台抽象层（仅接口）
        │    adc_stream / byte_stream / usb_device │
        ├──────────────────────────────────────────┤
        │  IMPLEMENT/impl_*.c                      │  平台实现层（适配）
        │    组装板级 platform 对象、转发中断      │
        ├──────────────────────────────────────────┤
        │  VENDOR/vendor_*.c                       │  驱动层（寄存器级）
        │    GPIO / TIM / ADC / DMA / USB CDC      │
        └──────────────────────────────────────────┘
```

**依赖方向**：上层只依赖 `platform_*.h` 中声明的抽象对象（`ops` 函数表 + `impl` 私有指针），不包含任何 `IMPLEMENT/` 或 `VENDOR/` 头文件。更换硬件方案时，只需替换 IMPLEMENT/VENDOR 两层。

| 层 | 目录 | 职责 |
|---|---|---|
| 应用层 | `APP/` | 初始化服务、主循环调度、串口调试遥测 |
| 服务层 | `SERVICE/` | ADC 数据流状态机、队列管理、命令解析、转速帧上报 |
| 平台抽象层 | `PLATFORM/` | ADC 采样流 / 字节流 / USB 设备 / 板级对象集合的纯接口定义 |
| 平台实现层 | `IMPLEMENT/` | 把抽象落到 STM32 硬件，组装板级对象，转发中断回调 |
| 驱动层 | `VENDOR/` | 寄存器级外设驱动与 USB CDC 协议栈封装 |
| 板级支持 | `SYSTEM/` | SysTick 延时、位带 GPIO 宏定义 |
| 启动与 CMSIS | `CORE/`、`USER/` | 启动汇编、向量表、中断服务例程、系统时钟初始化 |
| 外设库 | `FWLIB/` | ST 标准外设库（裁剪后按需参与编译） |
| USB 协议栈 | `USB/` | USB OTG 驱动 + CDC 类实现 + 用户配置 |

## 数据通路

```
编码器脉冲 ──▶ TIM2 触发 ──▶ ADC1 ──DMA──▶ 驱动层双缓冲
                                              │ 半满/满中断
                                              ▼
                        服务层 ADC 队列（16 KB 环形）
                                              │ poll 批量取 512 字节
                                              ▼
                                  USB CDC 发送端点 ──▶ 上位机

Z 相脉冲 ──▶ TIM5 时间戳 ──▶ 周期换算 ──▶ 转速帧（500 ms 周期）
```

- 采样中断只做「入队」，不做任何耗时操作
- 主循环 `poll` 每次最多搬运 512 字节到 USB 发送环
- 转速帧独立成帧，队列拥塞时直接丢弃，不排队、不补发

## 通信协议

USB CDC 虚拟串口，波特率设置对全速 USB 无效（任意值均可）。

### 上位机 → 设备（命令，2 字节）

| 命令 | 字节序列 | 作用 |
|---|---|---|
| 启动采集 | `4F 00`（`'O'` + `\0`） | 启动 TIM2 → ADC → DMA 采集，清空本地发送队列 |
| 停止采集 | `43 00`（`'C'` + `\0`） | 停止触发，冲刷 DMA 残余数据，队列发空后转入停止态 |

命令需以 `0x00` 结尾才会执行；未等到结尾字节时暂存，收到非命令字节则丢弃。

### 设备 → 上位机：ADC 数据流

启动采集后持续输出的**原始采样字节流**，无帧头、无分隔，连续不断：

```
[采样0][采样1][采样2]...
```

每个字节对应一次编码器触发产生的 ADC 采样值。

### 设备 → 上位机：转速帧（9 字节）

```
偏移  0    1    2    3    4..7        8
     A5   5A   52   04   RPM(小端)   CHK
```

| 字段 | 值 | 说明 |
|---|---|---|
| 帧头 | `A5 5A` | 固定 |
| 类型 | `52` | 转速帧 |
| 长度 | `04` | 载荷 4 字节 |
| 载荷 | uint32 小端 | 转速，单位 rpm |
| 校验 | uint8 | 前 8 字节累加和（自动截断） |

默认每 **500 ms** 上报一帧；转速超过 12000 rpm 或 Z 相超时则报 0。

## 构建与烧录

1. 用 **Keil MDK** 打开 `USER/USMART.uvprojx`
2. 编译（F7），输出到 `OBJ/`：`USMART.axf` / `USMART.hex`
3. 用 J-Link 烧录并复位运行

清理编译产物（删除各目录下的 `.o`、`.crf`、`.axf` 等）：

```
keilkilll.bat
```

> 注意：`OBJ/` 已在 `.gitignore` 中，编译产物不会进入版本库。

## 调试输出

USART1（PA9/PA10，**115200-8-N-1**）每秒输出一行运行遥测：

```
BOOT uart=115200 service=0 usb=data pa5=trigger pa2=adc pb12=z idle=wfi
EV START
D t=1234567 st=2 rpm=1500 h=42 f=21 n=86016 ... q=0 pk=3 ub=0 ue=0 p=0 rs=0 dr=0 mn=12 mx=241 ls=137 ov=0 z=8 zp=40000 hw=63
```

关键字段：

| 字段 | 含义 |
|---|---|
| `st` | 服务状态（0=未初始化 1=停止 2=采集中 3=暂停 4=错误） |
| `rpm` | 当前转速 |
| `h` / `f` | DMA 半满 / 满中断计数 |
| `n` | 已产出的采样字节数 |
| `q` / `pk` | 当前 / 峰值队列水位 |
| `ub` / `ue` | USB 忙返回次数 / 连续忙次数 |
| `p` / `rs` | 采样暂停 / 恢复次数 |
| `dr` | 丢弃采样字节数 |
| `mn` / `mx` / `ls` | ADC 最小值 / 最大值 / 最新值 |
| `ov` | ADC 溢出次数 |
| `te` / `de` / `fe` | DMA 传输 / 直接 / FIFO 错误计数 |
| `z` / `zp` | Z 相中断次数 / 最近周期（µs） |
| `hw` | 硬件状态位掩码 |

> `idle=wfi` 为预留的 Cortex-M4 Sleep 低功耗路径，当前在 `app_main.c` 主循环中**已注释**（USB 唤醒调试期间关闭）。

## 可调参数

集中在 `SERVICE/adc_stream_service.c` 顶部与 `VENDOR/vendor_stm32_encoder_adc.c` 顶部：

| 参数 | 默认值 | 位置 | 说明 |
|---|---|---|---|
| `TRIGGER_COUNTS` | 1 | SERVICE | 累计多少次编码器计数触发一次 ADC 采样 |
| `SPEED_UPDATE_MS` | 500 | SERVICE | 转速上报周期，同时作为停转超时 |
| `ENCODER_COUNTS_PER_REV` | 4000 | SERVICE | 编码器每转计数（当前测速用 Z 相周期，不用此值） |
| `ADC_QUEUE_SIZE` | 16384 | SERVICE | 服务层 ADC 字节环形队列容量 |
| `TX_CHUNK_SIZE` | 512 | SERVICE | 单次 poll 向 USB 写入的最大字节数 |
| `SPEED_FRAME_SIZE` | 9 | SERVICE | 转速帧长度 |
| `DMA_BUFFER_SIZE` | 1024 | VENDOR | ADC DMA 环形缓冲（半字） |
| `Z_MAX_VALID_RPM` | 12000 | VENDOR | 转速上限，超过则判为无效 |
