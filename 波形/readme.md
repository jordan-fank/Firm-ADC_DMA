为了解决我们这个项目最终生图有很多噪声的问题，我们做了以下实验，采集了不同情况下的波形，来探究可能出现的噪声问题

我先给你讲解实验背景

背景注意：
文件1-4两个通道本质上都是连接的传感器的ADC的接口

传感器和单片机之间是通过一根接近1米长的网口线连接的

我们为了研究这个数据线传输过程两端有没有信号干扰问题

我们也做了对比实验

就是通道1连接一端接近传感器的一端

通道2连接一端接近单片机的一端

编码器和单片机之间也是通过一根接近1米长的网口线连接的

而且之前编码器和传感器的两根传输线是相互缠绕在一起的

我们实验做了两个版本就是这两根线保持和之前合并以及两根线分开

以此来做串扰分析，就是传感器和编码器的传输线直接合并在一起会不会导致串扰

探针转和不转是有区别的，探针转就是代表真实测量圆壁，这个时候编码器是有信号的，感光芯片这个传感器的感光也就跟着转采集内壁信息

还有就是两个通道都接地了，共地

文件5和6是：通道1是编码器B相-通道2是传感器-线合并-探针不转和转

文件1-6的文件名都写清楚了这个波形具体是什么情况下采集的
